# Nathaniel Monteparte — UTA Portfolio

Static teaching portfolio for Writing for the Health Professions at the University of Maryland.

## Edit content

Edit `content.json` to update the homepage, artifacts, and reflections. Styling is in `styles.css`; page rendering is in `app.js`. Supporting PDFs are in `materials/`.

## Publish

GitHub Pages serves this repository from the root of the main branch. Changes publish automatically after they are pushed.
